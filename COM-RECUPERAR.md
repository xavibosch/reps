# Com recuperar home-gym al Mac

## 1. Baixar-lo

```bash
cd ~/Developer
git clone https://github.com/xavibosch/reps.git
cd reps
```

## 2. Deixar-lo a punt



### Dependències
```bash
npm install
```

### Executar
```bash
npm run dev
```

## 3. Guardar els canvis que facis

```bash
git add -A
git commit -m "què has canviat"
git push
```

## Què NO hi ha en aquest repositori

Dependències (`node_modules`, `.venv`), compilats (`build`, `dist`, DerivedData) i fitxers de claus (`.env`). Tot això es torna a generar amb els passos de dalt; les claus les has de tornar a posar tu.
