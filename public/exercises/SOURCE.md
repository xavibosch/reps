# Where these photos come from

[free-exercise-db](https://github.com/yuhonas/free-exercise-db), released under
the **Unlicense**, which places the work in the public domain. No attribution is
required; this file is here so nobody has to re-derive the provenance later.

Two frames per exercise, the start and the end of the rep, cycled in the app to
stand in for the looping GIF the design asked for.

The exercise GIFs most gym apps use (MuscleWiki, GymVisual and similar) are
copyrighted and cannot be bundled here, which is why these are photographs
rather than animations.

One substitution worth knowing: the dataset has no rear-foot-elevated split
squat, so **Bulgarian Split Squat** shows `Split Squat with Dumbbells`.

Regenerate or extend with the mapping in the download script; keep filenames as
`<slug-of-exercise-name>-<0|1>.jpg`, because `src/lib/store.ts` derives the path
from the exercise name rather than storing it.
